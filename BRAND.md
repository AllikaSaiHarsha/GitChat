# Purlway brand guide

## Position

Purlway is a calm, lightweight home for team conversations. The name pairs the
purl stitch, a basic knitting pattern, with the idea of a path that connects
people. The promise is simple: keep conversations moving without adding noise.

**Tagline:** Team chat, in flow.

## Identity

The mark brings two conversation loops together with a continuous thread and a
small check-shaped crossing. Use it in the rounded copper badge in the app
header and sign-in screen, or as the standalone favicon. Keep the mark at its
intrinsic proportions and leave clear space around it equal to the width of
one thread stroke. Use the wordmark in title case: **Purlway**.

## Color

| Role | Color | Use |
| --- | --- | --- |
| Deep ink | `#17191e` | App canvas and browser theme |
| Raised ink | `#24262d` | Panels, navigation, dialogs |
| Linen | `#f0ece7` | Main text on dark surfaces |
| Muted linen | `#b8b0aa` | Supporting text and hints |
| Copper | `#e7a176` | Primary actions, focus, selection, and the mark |
| Copper light | `#f2b88f` | Hover and active emphasis |
| Soft green | `#93c5a9` | Presence and success states |
| Linen link | `#ffc49c` | Links on dark surfaces |

Keep semantic warning and error colors separate from the brand palette. Always
retain the visible keyboard focus ring and check text contrast when adding a
new color pairing.

## Type and voice

Use the existing system sans-serif stack for interface text and the monospace
stack for code. Keep headings compact and readable. Write in a clear, warm, and
steady voice. Prefer short action labels and plain explanations; avoid urgency
unless the situation truly requires it.
